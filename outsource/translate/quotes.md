## 2026-10-19 마이트랜스 — 카탈로그 영한 번역

- 원본: `[마이트랜스]_크림슨에듀케이션_2026_1019_카달로그 영한 번역.xls` (Downloads, 저장소 미포함)
- 업체 담당자: 김은산 팀장
- 수신 참조: 윤희상님
- 계산: 8페이지 × 40,000원 = 320,000원, 단위절사 −20,000원 → 공급가 300,000원 + 부가세 30,000원 = **330,000원**
- 페이지 기준: 외국어→한국어는 외국어 250단어 = 1페이지 (1,958 ÷ 250 ≈ 7.8 → 8페이지)
- 결제조건: 사용자가 10-21 답변 메일에 작성해 전달함 (납품일은 같은 날 업체 회신으로 확정)
- 2026-10-20: 발주하기로 결정(Harry). 다음: 업체에 발주 통보 + 납품일·결제조건 확인 → 납품 시 상태 "납품", 정산 시 "정산"으로 갱신
- 2026-10-21: 업체 회신 — 10-22(목)까지 마감 목표, 하루 늦으면 10-23(금) 오전까지 납품. 결제조건은 사용자가 답변 메일로 전달
