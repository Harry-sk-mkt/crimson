# Context Index

`context/*.md`에 쌓인 기록을 날짜 파일 안 뒤지고 바로 찾기 위한 토픽 인덱스. 새 `context/YYYY-MM-DD.md` 항목을 쓸 때마다 한 줄씩 추가한다(소급 작성 안 함, 작성 시점부터 누적).

형식: `- [YYYY-MM-DD] 한 줄 요약 — YYYY-MM-DD.md#헤더`

(나중에 Obsidian을 vault로 쓰게 되면 `파일#헤더` 표기를 `[[파일#헤더]]`로 바꾸면 자동 백링크·그래프뷰가 됨 — 지금은 일반 텍스트 포인터로 둠)
