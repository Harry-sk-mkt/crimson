## Claude Code

- **무엇을 리서치/결정했는지**: 리센느(RESCENE) 역주행 사례를 소크라테스식 대화로 분석해 브랜딩 프레임워크로 정리 (`projects/branding/context.md`, crimson 저장소 밖 별도 폴더). 언더독+노력서사+친밀감→밈 증폭→[친밀감 유지, 실력/매력] 두 독립 필요조건 충족 시 지속성장이라는 모델 도출(리센느/유영우/홍박사 사례로 검증). 이어서 이 모델을 크림슨 브랜딩에 적용 — 크림슨은 업계 1위라 언더독 포지션 불가하므로, 당사자형(리센느) 대신 발굴자형(케이카가 원이를 발굴한 패턴) 모델로 역전 적용.
- **왜**: 사용자가 크림슨 브랜딩 프로젝트 아이디어(원이 같은 열심히 하는 학생을 발굴해 서비스 지원, 콘텐츠는 "노력"을 직접 말하지 않고 진짜 모습만 보여줘서 대중이 서사를 스스로 발견하게 하는 방식)를 구체화하는 과정에서 리센느 케이스를 참고 프레임으로 사용.
- **다음 액션 (미결)**: (1) 학생 선발 기준에 "실력/매력" 축을 어떻게 넣을지 미정 (2) "서비스 지원"이 크림슨의 어떤 실제 서비스/프로덕트인지 미정. 다음 세션에서 이 두 지점부터 이어가면 됨. 상세 내용/근거 소스는 `projects/branding/context.md` 참고.
