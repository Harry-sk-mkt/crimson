# 케이스 스터디 요약 — 사용자 교정 패턴

Claude가 쓴 요약(`snapshots/*.before.md`)과 사용자가 문맥·단어를 교정한 Notion 최종본을 비교해 쌓는 학습 기록. 다음 케이스 요약을 쓰기 전에 이 파일을 먼저 읽고 반영한다. (`writing/copy-review-patterns.md`와 같은 방식)

## 비교 절차

1. 요약을 Notion에 올린 직후 `snapshots/YYYY-MM-DD-<페이지명>.before.md`로 Claude 작성분만 저장
2. 사용자가 교정 완료를 알리면 Notion 페이지를 다시 fetch해 스냅샷과 비교
3. 바뀐 부분을 아래 형식으로 기록: 전 → 후, 왜 바뀐 것으로 보이는지(추정이면 추정이라고 표기), 일반화한 규칙
4. 일회성 사실 수정(숫자·이름 오류)과 반복될 스타일 패턴을 구분해서 적는다
