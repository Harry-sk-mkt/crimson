# 케이스 스터디 요약 — 사용자 교정 패턴

Claude가 쓴 요약(`snapshots/*.before.md`)과 사용자가 문맥·단어를 교정한 Notion 최종본을 비교해 쌓는 학습 기록. 다음 케이스 요약을 쓰기 전에 이 파일을 먼저 읽고 반영한다. (`writing/copy-review-patterns.md`와 같은 방식)

## 비교 절차

1. 요약을 Notion에 올린 직후 `snapshots/YYYY-MM-DD-<페이지명>.before.md`로 Claude 작성분만 저장
2. 사용자가 교정 완료를 알리면 Notion 페이지를 다시 fetch해 스냅샷과 비교
3. 바뀐 부분을 아래 형식으로 기록: 전 → 후, 왜 바뀐 것으로 보이는지(추정이면 추정이라고 표기), 일반화한 규칙
4. 일회성 사실 수정(숫자·이름 오류)과 반복될 스타일 패턴을 구분해서 적는다

## 패턴

### 2026-09-23 Scarlett Dental (첫 비교)

**반복될 스타일 패턴**

1. **상대 시점보다 실제 날짜를 쓴다**
   - 전: "11학년 봄에 늦게 합류했지만"
   - 후: "2025년 3월 늦게 합류했지만"
   - 추정 이유: 학년·계절 표현은 학제마다 해석이 달라 모호함. 원자료에 날짜가 있으면 날짜가 정확함.
   - 규칙: 원자료에 연월이 있으면 한 줄 요약에서도 연월로 쓴다. (학년 표기는 "합류 전 → 합류 후" 같은 흐름 섹션에서만)
2. **내부 문서 본문에서는 고유명사를 가리지 않는다**
   - 전: "외부 기관과 연결해"
   - 후: "Bakara Library 외부 기관과 연결해"
   - 추정 이유: 이 페이지는 내부 정리본이고, 가리는 작업은 슬라이드로 옮길 때 "공개 시 가릴 것" 섹션 기준으로 한다.
   - 규칙: 본문에는 기관·프로그램 이름을 그대로 쓰고, 공개 리스크는 "공개 시 가릴 것"에만 적는다. 미리 익명화하지 않는다.
3. **원자료 값은 형식 그대로 남긴다**
   - 전: "학교 석차는 N/A였어요"
   - 후: "학교 석차는 na/98이였어요"
   - 추정 이유: 분모(학년 인원 98명)가 "상위 약 10%" 추정의 근거라 빠지면 안 됨.
   - 규칙: 수치는 분모·단위까지 원자료 형식으로 적는다. 추정치를 쓸 때는 그 근거가 된 값도 같이 남긴다.

**페이지 구성**

- 사용자가 맨 위에 Student Roadmap(외부 임베드)을 두고, 직접 쓴 메모를 원문 토글 아래(페이지 맨 끝)로 옮겼다.
- 규칙: 로드맵 링크 → Claude 요약 → 원문 토글 → 사용자 메모 순서. 요약을 쓸 때 사용자 메모 위치를 건드리지 않는다.

**일회성 사실 수정:** 없음

**참고:** 사용자 메모는 "baraka", 교정본은 "Bakara Library"로 표기가 다르다. 정식 명칭 미확인.
