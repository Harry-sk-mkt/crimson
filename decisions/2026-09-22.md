## 오전 — Claude Code (환경 이전 잡일)

- macOS 환경으로 이전. 업데이트 전 설치한 Antigravity IDE가 Applications에서 안 보이던 문제 → 실제로는 `/Applications/Antigravity IDE.app`에 정상 설치돼 있었고 Spotlight 재인덱싱(`mdimport`)으로 해결 (Launchpad 캐시 문제로 추정).
- 설치용 dmg(`Antigravity IDE.dmg`, `Antigravity.dmg`)는 Downloads에서 Trash로 이동 시도했으나, dmg가 마운트된 `/Volumes/Antigravity IDE`에서 현재 Claude Code 세션이 구동되는 Antigravity IDE 인스턴스가 실행 중이라 unmount 불가 — **보류 상태**. 이 IDE 창을 닫을 수 있게 되면 (Applications 버전으로 새로 열거나 세션 종료 후) 마운트 해제 + dmg 삭제 마저 진행 필요.
- Dock에 Antigravity IDE 추가: `dockutil`/`brew` 없어서 `~/Library/Preferences/com.apple.dock.plist`를 python으로 직접 수정 (persistent-apps에 항목 추가). **Dock 재시작(`killall Dock`)은 아직 안 함** — 사용자 확인 후 진행 예정.
