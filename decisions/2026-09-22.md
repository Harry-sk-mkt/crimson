## 늦은 오후 — Claude Code

**결정**: 회의 자동화 도구로 Vexa(오픈소스 셀프호스트 meeting-bot, Apache-2.0)를 선택하고 셀프호스팅 시도. tl;dv(클라우드, 무료, Notion 네이티브 연동)와 비교했을 때 데이터 제어권 우선으로 Vexa 선택.

**진행 상황**:
- Docker Desktop 신규 설치 (`/Applications/Docker.app`, PATH는 `~/.zshrc`에 `~/.docker/bin` 추가로 해결). Docker Hub 로그인 완료.
- `~/vexa`에 클론. 레포 자체 이슈 2개를 로컬 clone에서 직접 수정: (1) MinIO가 Docker Hub에서 내려가서 `quay.io/minio/*`로 경로 변경, (2) `INTERNAL_API_SECRET`/`VEXA_FLOWS_API_KEY`가 기본값 없는 필수 시크릿이라 `openssl rand -hex 32`로 직접 발급.
- `make all` 성공 — Terminal UI `localhost:13000`, API gateway `localhost:18056`, 셀프호스트 API 키 발급됨 (`vxa_bot_...`, `~/vexa/deploy/compose/.env`).
- **막힌 지점**: hosted STT(`vxa.ai/account`에서 받은 토큰, `vxa_tx_...`)를 붙이려 했으나 hosted 엔드포인트(`https://transcription.vexa.ai`)가 `Idempotency-Key` 헤더 미비로 현재 400 에러 나는 미해결 버그([vexa#1344](https://github.com/Vexa-ai/vexa/issues/1344), open, 2026-08-25경부터). 로컬 CPU 전사 유닛(`deploy/transcription`, `docker-compose.cpu.yml`, MODEL_SIZE=small)으로 전환 시작했으나 `docker compose ... up -d --build` 실행 직전에 미팅 때문에 **중단** — 아직 안 뜬 상태.
- 회의 형태 확인: 온라인(Meet/Zoom) + 대면 혼합. 대면 회의는 Vexa 대상이 아니고(봇이 참여할 온라인 URL이 없음) Vibe로 처리, Vexa는 온라인 회의 전용.

**다음 액션**: `cd ~/vexa/deploy/transcription && docker compose -f docker-compose.cpu.yml up -d --build` 마저 실행 → 뜨면 메인 스택 `.env`의 `TRANSCRIPTION_SERVICE_URL=http://host.docker.internal:8083`, `TRANSCRIPTION_SERVICE_TOKEN=`(transcription/.env의 API_TOKEN과 동일값)로 설정 → `make all` 재실행 → Google Meet 테스트.

**검증됨 (오전 질문에 대한 답)**: Vibe 자체는 meeting-bot이 아니라서 "API로 자동화"는 `--server` HTTP 모드가 아니라 **`vibe-server transcribe <model> <audio.wav>` CLI**로 이미 가능함을 실제 회의 녹음(아래)으로 검증 완료. `--word-timestamps` 옵션은 한국어에서 토큰 중간이 끊겨 `�` 깨짐이 생기므로 쓰지 말 것 — 옵션 없이 문장 단위로 돌리면 깨끗함.

**오늘 그로스 미팅 처리**: 10:43 녹음 → `vibe-server transcribe`로 전사 → `meetings/growth-meeting/2026-09-22.md`에 원문 텍스트 저장 완료. Notion(`dbGm`) 페이지는 **미생성** — 사용자가 다른 컴퓨터에서 제목 정하고 직접 만들기로 함. 원본 오디오(`~/Documents/Vibe/Record-2026-09-22 10-43-23-.../audio.wav`)는 지워도 되는 것으로 확인됨(텍스트만 보존 대상).

## 저녁 — Claude Code (세일즈 마케팅 미팅 처리 + 워크플로 정비)

**처리**: 13:21 녹음(72분, "세일즈 마케팅 미팅")을 `vibe-server transcribe`로 전사 → `meetings/sales-marketing/2026-09-22.md` 저장 + Notion(`dbInCorpMeeting`, Tags=Team) 페이지 생성. "세일즈 마케팅"은 기존 매칭 키워드(1:1/이벤트리뷰/아이디에이션/그로스)에 없던 미매칭 제목이라 사용자 확인 후 `sales-marketing/` 카테고리를 신설(정기 회의, 주 1회로 `_index.md` 갱신).

**전사 품질 이슈 발견 및 대응**:
- 72분 파일을 통째로 돌리면 hallucination 반복 루프 발생 ("스탠포드에 합격시킨" 등 수백 회 반복). 10분 단위, 필요시 2분 단위로 분할 재전사해서 해결.
- `--word-timestamps`는 한글 멀티바이트 문자를 깨뜨림(예: "제주도"→"제주■") — 쓰지 않기로 확정.
- 기본값(temperature=0 그리디)도 반복 루프 유발 — 앱 실제 설정값(`beam-size 5 --best-of 5 --temperature 0.4 --threads 4`)으로 고정.
- 위 내용 전부 `meetings/CLAUDE.md`에 반영.

**운영 개선**:
- Notion `notion-create-pages`에 `parent`(data_source_id) 안 넣으면 속성이 빈 독립 페이지로 만들어지는 함정 발견 → `move-pages`+`update-page`로 사후 수정. 앞으로는 항상 parent 지정.
- 권한 프롬프트가 잦은 원인 확인: 기존 allow 규칙 대부분이 세션별 스크래치패드 UUID 경로/PID 등 정확히 그 한 번만 맞는 문자열이었음. `.claude/settings.local.json`에 vibe/ffmpeg/kill/chmod/nohup/awk/wc 및 `meetings/` 폴더 Edit·Write를 와일드카드로 일반화해서 다음부터 덜 물어보게 함.
- 문장별 줄바꿈 포맷을 2026-09-22 이후 신규 회의록부터 적용하기로 결정(기존 파일은 소급 수정 안 함). 화자 diarization은 Vibe/whisper.cpp에 없는 기능임을 확인 — 필요시 별도 도구(pyannote 등) 도입 필요, 요청 전 임의 진행 금지로 규칙화.

**미해결**: Vibe 녹음 파일(오디오)을 맥↔윈도우 자동 동기화하는 방법 — 이 맥은 iCloud Drive 문서 동기화가 꺼져있어 현재 자동 동기화 없음. 사용자가 "그냥 맥에서 계속 작업"으로 보류.

## 오전 — Claude Code (환경 이전 잡일)

- macOS 환경으로 이전. 업데이트 전 설치한 Antigravity IDE가 Applications에서 안 보이던 문제 → 실제로는 `/Applications/Antigravity IDE.app`에 정상 설치돼 있었고 Spotlight 재인덱싱(`mdimport`)으로 해결 (Launchpad 캐시 문제로 추정).
- 설치용 dmg(`Antigravity IDE.dmg`, `Antigravity.dmg`)는 Downloads에서 Trash로 이동 시도했으나, dmg가 마운트된 `/Volumes/Antigravity IDE`에서 현재 Claude Code 세션이 구동되는 Antigravity IDE 인스턴스가 실행 중이라 unmount 불가 — **보류 상태**. 이 IDE 창을 닫을 수 있게 되면 (Applications 버전으로 새로 열거나 세션 종료 후) 마운트 해제 + dmg 삭제 마저 진행 필요.
- Dock에 Antigravity IDE 추가: `dockutil`/`brew` 없어서 `~/Library/Preferences/com.apple.dock.plist`를 python으로 직접 수정 (persistent-apps에 항목 추가). **Dock 재시작(`killall Dock`)은 아직 안 함** — 사용자 확인 후 진행 예정.
