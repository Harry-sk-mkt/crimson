- 지원자별 폴더, 면접 하나당 파일 하나: `interview/<지원자 이름>/YYYY-MM-DD.md` (전사 원문, 문장 단위 줄바꿈)

## 2. 작업 원칙 (Harry와 일하는 방식)

### 사용자 기본 선호 (최우선)

- **추측하지 말 것.** 무언가를 가정해야 한다면 먼저 사용자에게 물어볼 것.
- **사용자가 제공한 지식(이 파일, 프로젝트 문서)을 먼저 사용할 것.** Claude 자체 지식으로 답을 보강하려면 사용자에게 먼저 확인받을 것.

### 채용 업무 스타일

- Harry는 짧은 축약형 한국어로 지시한다 → Claude는 이를 정제된 비즈니스 한국어(이메일, 평가표, 질문지)로 확장한다. 추가 설명을 요구하지 말 것.
- 초안 작성 전, 필요한 경우 **핵심을 짚는 확인 질문**을 먼저 한다. 디테일을 임의로 채우지 않는다.
- **일관성 유지:** 모든 지원자에게 같은 프로세스 구조, 같은 커뮤니케이션 템플릿, 같은 평가 프레임워크를 적용한다.
- Harry는 진행 중에 자신의 판단에 따라 채점 기준을 수정한다 → 수정 사항은 공통 프레임워크에 반영한다.
- 면접 질문지 기본 흐름: 자기소개 → 대표 프로젝트 딥다이브 → 실패와 학습 → AI 활용 → 연봉 확인 → 지원자 질문 → 프로세스 안내. 포지션/지원자별 섹션은 필요 시 추가.
- 질문지는 이전 단계(서류·전화·과제)에서 발견한 **갭(주장 vs 실제)을 정면으로 재확인**하도록 설계하고, 각 질문이 어느 평가 항목 채점에 쓰이는지 표기한다.
- Harry 본인의 매니지먼트 스타일에 대한 동료 피드백(데이터 기반, 순차적 가설 검증, 주간 리뷰, 월간 1:1)은 공고 톤 설정의 내부 참고 자료로만 쓰고 직접 인용하지 않는다.

### 평가 철학 (Key learnings)

- 채점은 표면적 실행 품질보다 **전략적 사고와 퍼널 로직**에 가중치를 둔다.
- 서류 단계에서는 애매하면 탈락시키지 말고 "조건부 합격 + 전화면접 확인 질문"으로 넘긴다.
- 지원자 커뮤니케이션은 내부 최종 결정 전까지 **중립**을 유지한다. 모든 면접이 끝나기 전에는 오퍼를 암시하지 않는다.
- 공고 v1의 문제: 자격 미달 지원자 과다 + 기대치 불명확으로 중간 단계 이탈.
- 공고 v2의 해결책: 실무/프로젝트 경험 요구, KPI 기반 성과 측정 명시, 다단계 프로세스 사전 공개.

### 문서 작성 규칙

- 지원자 문서 파일명/제목 형식: `YYYY-MM-DD <지원자명> <문서종류>` (예: `2026-08-26 한나영 실무 면접 평가 결과`)
- 평가 결과 문서 구성: 채점 시트(항목/배점/점수/근거) → 종합 의견 → 최종 판정(합격/보류/불합격 체크박스)
- 최종 판정은 "팀 논의로 확정 필요" 형태로 제안만 하고 단정하지 않는다.

## 4. 공통 평가 프레임워크

### 4.1 서류전형 평가 프레임워크 (공통, 자기소개서·포트폴리오 기준)

- 적용 대상: 자기소개서 + 포트폴리오(또는 이력서)로 진행하는 서류전형 단계
- 목적: 서류전형에서는 명백한 결격 사유만 걸러내고, 서류만으로 확정 판단이 어려운 항목은 "조건부 합격 + 전화면접 확인 질문"으로 이관한다. 애매한 우려 사항을 근거로 서류 단계에서 성급하게 불합격 처리하지 않는다.
- 2026-08-19 이민영 지원자(크림슨에듀케이션코리아 주니어 마케터 JD 기준) 평가 과정에서 합의된 기준을 프레임워크로 정리함.

#### 평가 항목 (4개)

##### 1. 실제 성과 수치의 구체성/신빙성
- 체크 포인트: 수치가 구체적인가(%, 절대값, 기간, 예산 규모), 비교 기준(대비 시점)이 명시돼 있는가
- 긍정 신호: 브랜드/프로젝트별 본인 기여도(%)를 스스로 명시 — 과장을 자제하려는 태도로 해석, 신뢰도를 높이는 요소
- 부정 신호: 정성적 서술만 있고 수치 근거가 없음, 모든 프로젝트를 100% 본인 기여로 일괄 서술
- 필수 확인 사항: 포트폴리오 내 성과 그래프/차트의 기간이 본인이 명시한 재직 기간과 일치하는지 (재직 전/후 실적이 섞여 들어가 있지 않은지) — 불일치 발견 시 전화면접 확인 리스트에 추가

##### 2. 자기소개서-포트폴리오 정합성
- 체크 포인트: 자소서에서 주장하는 역량·경험이 포트폴리오의 실제 사례로 뒷받침되는가
- 부정 신호: 자소서에는 강한 표현(예: "캠페인을 설정하여 집행", "전 과정을 주도")이 쓰였는데, 포트폴리오·경력 사항을 보면 실제로는 보조·콘텐츠 제작 수준에 그치는 등 표현과 실체 간 간극이 있는 경우
- 참고 사례: 한나영 지원자 — 자소서상 "메타 광고 매니저로 캠페인 설정·집행"이라 서술했으나 실제로는 유료 캠페인 운영 경험 없이 콘텐츠 제작 위주였음이 전화면접에서 확인됨(대표적 반례)

##### 3. 직무 적합성 (매체 운영 범위)
- 체크 포인트: 다뤄본 매체의 종류·폭, 업무 범위(세팅~집행~분석~보고 전체 흐름을 경험했는지)
- 원칙 ①: 지원자의 이전 산업/업종이 지원 회사와 다르다는 것 자체는 서류 단계 감점 요인으로 쓰지 않는다. 마케팅은 직군 특성상 역량이 도메인 간 전이 가능하다고 본다.
- 원칙 ②: JD에 명시된 특정 툴(예: Canva, Marketo 등)을 다뤄본 지원자가 채용 시장에 실질적으로 드문 경우, 이를 하드 필터(자동 감점/탈락 사유)로 쓰지 않는다. 대신 매체 운영·데이터 분석·캠페인 기획 등 실무에서 보편적으로 요구되는 역량의 폭과 깊이를 기준으로 판단한다.

##### 4. 경력 연속성 / 이직 주기
- 체크 포인트: 재직 공백 기간, 단기 재직(대략 6개월 미만) 여부, 현재 직장 재직 기간 대비 이직 시도 시점
- 원칙: 공백기·단기 재직 자체는 서류 단계에서 자동 불합격 사유로 쓰지 않는다. 서류만으로는 사유(이직 사유, 권고사직, 개인 사정 등)를 알 수 없기 때문에 "조건부 합격 + 전화면접에서 사유 확인" 방식으로 처리한다.
- 전화면접 확인 질문 템플릿:
  - 공백기 동안 어떤 활동을 했는지

- 4개 항목 중 다음에 해당하는 **명백한 결격 사유**가 없으면 원칙적으로 서류 합격 처리한다:

  - 자소서-포트폴리오 간 심각하고 반복적인 모순
- 이직 주기, 성과 수치의 시점 불일치 등 서류만으로 확정 판단이 어려운 항목은 "확인 필요" 리스트로 정리해 전화면접 질문지에 반영한다.

### 4.3 과제 제출 평가 프레임워크 (공통, Meta 광고 소재 과제 기준)

- 적용 대상: "메타 광고용 스태틱(이미지) 소재 1개 제작 + 제작 의도·기획 배경(1~2문단)" 과제 전형
- 목적: 단순 디자인 완성도가 아니라, 지원자가 고객 관점에서 설득력 있는 가치 제안을 만들 수 있는지, 그리고 그 결과물 뒤에 타겟팅·경쟁사·시장에 대한 전략적 사고가 있는지를 함께 평가한다.
- 2026-08-20 한나영 지원자 과제 평가 과정에서 합의된 관점을 프레임워크로 정리함: 평가는 크게 두 축으로 나눠서 본다.
  - 소재 자체의 성능(설득력): 타겟팅 정교함 + Value Proposition + Cost 시각화/소구 강도

  - 두 축을 분리해서 보는 이유: 리서치는 탄탄한데 정작 소재가 "회사가 하고 싶은 말"에 머무는 경우, 반대로 소재는 그럴싸한데 근거가 얕은 경우를 구분해서 진단하기 위함.
