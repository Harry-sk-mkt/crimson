# Copy Library 검수 패턴 (학습 기록)

`db_copy`에서 `isReviewed`가 체크된 페이지의 legacy 원문과 최종본을 비교해서 뽑은 패턴입니다. 규칙 목록이 아니라 사례에서 배운 경향입니다. 새로 검수된 페이지가 생기면 같은 방식으로 비교해서 갱신합니다.

- 마지막 갱신: 2026-09-23
- 학습한 사례: 4건 (legacy 토글이 있는 페이지만. 토글 이름은 `legacy` 또는 `before review`)
- legacy 토글 없이 체크된 5건은 비교할 원문이 없어 제외: 9/19 웨비나 녹화본, DUKE CAO, 9/22 Seminar - Transfer, Winter EC Planning, 9/16 WB - Angle Changed

## 적용 순서

1. Quality Bar [Creative & funnel](https://app.notion.com/p/3e064dfd498f80cc94d7d268bb55ba6e) 중 카피에 해당하는 항목
   - 타깃이 구체적인가 ("학부모"가 아니라 "G10–11 학부모")
   - 근거가 구체적인가
   - Target, Value, Cost를 모두 포함하는가
   - 아마추어 느낌이 나지 않는가
   - 소재 → 전환 → 컨텐츠 내용이 일관적인가
   - "진짜 한국인"처럼 이미 사실인 것을 오히려 왜곡되어 보이게 표현하지 않았는가
2. 아래 학습 패턴

## 학습 패턴

사례 수가 적어서 모두 잠정입니다. 괄호 안은 근거가 된 사례 수입니다.

### 1. 단정·과장·겁주는 표현을 뺀다 (4/4)
- "정답은 NO!!", "합격이 불가합니다" → 삭제하고 질문과 근거로 바꿈 (9/30 Indigo)
- "냉정하게도, 매년 만점짜리 성적표를 들고도 고배를 마시는 학생들이 수두룩합니다" → "동일한 성적, 동일한 활동으로도 얼리 혹은 레귤러 전형 선택에 따라 입시 결과는 완전히 뒤바뀌게 된다는 사실!" (10/14 WB)
- "단순한 학력 자랑글 NOPE ⛔" → 삭제 (NYT Jamie)

### 2. 막연한 주장 대신 구체 근거를 넣는다 (4/4)
- 마감일: "⏰ 11월 1일까지 지원 마감" (10/14 WB)
- 분석 대상 수: "스탠포드 합격자 3명의 리서치 프로젝트 분석" (9/30 Indigo)
- 원문 인용과 실제 이력 나열: "학위만 12개?🔥" → 인터뷰 인용문 + 하버드·스탠포드 MBA·예일 로스쿨·옥스퍼드 박사 등 실제 학위 (NYT Jamie)
- 비교 조건 통제: "동일한 성적, 동일한 활동으로도" (10/14 WB)

### 3. 여러 학교 묶음을 학교 하나로 좁힌다 (2/4, 나머지 2건은 원래 한 학교)
- "HYPS 입학사정관" → "하버드 입학사정관" (10/3 WB)
- "HYPSM 동시 합격자 90%" → "스탠포드 합격자들 90%" (9/30 Indigo)
- Heading에 쓴 학교와 본문 학교를 맞춘다

### 4. 다른 캠페인에서 가져온 특정 타겟 문구를 뺀다 (2/4)
- "채드윅 10학년 초보맘 필수" Heading 삭제 (10/3 WB, 9/30 Indigo)
- "채드윅 10학년, 이과 전공 아니면…" 도입부 삭제 (9/30 Indigo)

### 5. 훅을 우리 자랑에서 학부모의 고민으로 옮긴다 (1/4)
- "하버드·스탠포드·예일·옥스퍼드까지 취득 학위만 12개?" → "어릴 때부터 아이비리그를 준비시키는 게 맞을까요, 그냥 행복한 어린 시절을 보내게 두는 게 맞을까요?" (NYT Jamie)

### 6. Headings·NL 후보를 줄인다 (3/4)
- NYT Jamie: Headings 3 → 1, NL 3 → 1
- 10/3 WB: Headings 3 → 1
- 10/14 WB: Headings 3 → 2

### 7. 사실·표기 오류를 고친다 (1/4)
- 일시가 다른 이벤트 것으로 들어가 있던 것 수정: "9월 30일 (수) 오후 7:00" → "10월 3일 (토) 오전 10:30" (10/3 WB). 다른 소재를 복제해서 만들 때 생기는 오류로 보인다
- 짝이 안 맞는 따옴표 수정: ‘직접” → ‘직접’ (10/3 WB)

### 8. 업계 용어는 풀어 쓴다 (1/4)
- "시뮬레이션하는" → "입학처에서 하듯 가상 평가하는" (10/3 WB)
- "합격 기준" → "평가 기준" (10/3 WB)
